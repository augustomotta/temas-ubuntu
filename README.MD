Customizações:

1. Tema de boot (plymouth)
2. Wallpaper de tela de login
3. Wallpaper Desktop

Comando Flameshot para atalho do teclado   
sh -c "QT_QPA_PLATFORM=wayland flameshot gui"   


Instalação via Flatpak (Recomendado)   
   
Certifique-se de ter o Flatpak instalado e configurado no seu Ubuntu.   
   
Abra o terminal e execute o comando:   
   
flatpak install flathub io.github.vikdevelop.SaveDesktop   
   
Após a instalação, você pode abrir o aplicativo pelo menu de aplicativos ou usando:   
   
flatpak run io.github.vikdevelop.SaveDesktop
